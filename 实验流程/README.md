## 已定纪律（跨阶段适用）

1. **证据纪律**：进入图谱的事实边，证据指针只指向本三册语料；外部资料（大观复述/望谟本/云村寨/非遗页）只作 sameAs、版本链与背景属性（设计方案 §4.2）。
2. **事实层基准**：以古歌本（望谟系黄义仁简本，约 560 行）为准；版本差异按地域谱系登记，不覆盖事实层。
3. **抽取规则**：边界句按语义事件挂拍（p914 归 beat 3 引段）；复沓句只在首次叙述位抽事实边、台词位仅作佐证；起兴/比喻句不作事实证据（§2.4(3)）。
4. **敏感表述**：忠实转写原文 + 页码，加 `cultural_note` 说明神话语境，不做现代伦理改写（风险 #7）。
5. **canon 纪律**：canon 升版时按 `识别版本说明.md` 的版本对照表迁移指针。
