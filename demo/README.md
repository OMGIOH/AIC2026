# demo —— 初步知识图谱（S0–S2 数据预览）

> **这不是 S4 正式产出**，是 S0–S2 完成后先行出的预览版：把 S1 白名单实体 + S2 三轮抽取结果合并成一张可交互的图，验证「图谱长什么样、证据怎么呈现」，为 S4（落库与可视化）探路。

## 打开方式

直接双击 `index.html` 即可（自包含单文件，数据已内嵌，无网络依赖，file:// 可开）。

或本地起服务：`python3 -m http.server` 后访问 `/demo/index.html`。

## 页面内容（四视图）

- **图谱**：力导引图。节点按 S1 类型着色（人物红/神灵紫/角色金/地点绿/器物褐/歌篇蓝…），实线=事实层、蓝虚线=版本链、紫虚线=跨册/平行；有向边带箭头（对称边无箭头）。**点击任意节点小球，整个主区域直接切换到「实体页」**：图片位/视频位自动加载 `images/{实体id}.jpg`、`videos/{实体id}.mp4`，人物 5 位为真实媒体，其余类型显示「素材待补（演绎位）」占位+ 别名考订/称形/属性/参与事件/关联边双栏，「← 返回图谱」切回；顶部出现「实体页」标签可来回切。边点击后在右侧面板看详情与语料引文（页·行+原文）。左侧图例可按类型/层级筛选，支持搜索、拖拽、缩放。
- **事件**：十四节拍时间线，节拍 7 内嵌三对斗法子事件（灾/解对照）；参与实体 chips 可点击跳转实体页；点击卡片看逐条引文与大观《穆播董》平行段落。
- **实体**：S1 白名单全部 39 项分组表格，标注「在图谱 / 未入边 / 外部占位」；点任意行进入实体页。

## 建图口径（demo 专用约定）

1. **入图节点 = 被 S2 引用的实体**（三元组头尾 ∪ 事件参与者 ∪ 属性主体），共白名单 29 项；其余 10 项（龙王/雷公、部分地点/器物）仅列于实体视图标「未入边」。
2. **外部版本件 11 项为占位节点**：S2 版本层边（version_of/sameAs/parallel_piece/属体系）引用了 `piece_wangmo1994` 等不在 S1 白名单的 ID，demo 临时补灰色虚线节点（名称取自 S0 `bibliography.json`），正式登记留待 S4。
3. 证据指针瘦身为 `page·line + 引文`，canon 仍标注 v1.0-ocr；外部资料的指针不展示（只展示边关系本身）。
4. 边的 `verified` 状态（S3 回验结果）暂未展示，S3 完成后接入。

## 已知取舍

- 布局常显微动（alpha 下限 0.018，永不冷透）：图保持「活」的状态，拖拽节点/切筛选会把能量重新拉满再收敛；静止时仍可精确点击。
- 图谱中心（安王/后母一带）边密集，默认缩放下标签有重叠——可滚轮放大或关闭「边关系标签」。
- 只出现在事件里、无三元组边的角色（鹰使/鸦使/百姓等）悬浮在图外围，属预期（其关系走事件层表达）。
- 龙王「首见 p121」为大观本指针，实体表未区分册名，demo 阶段从简。
