## v1.2-ocr：视觉行聚类，修行内词序

| 项 | 内容 |
|---|---|
| 问题 | 同一视觉行内词序错乱（p200 直译行应为「欢 蹦眺 下 街」，实排成「街 / 蹦眺 / 欢 / 下」） |
| 原因 | Vision 对同一行各块的 y 估计有抖动（全册中位 4px），按 y 排序即错位 |
| 判据 | 重叠 ≥ 60% × max(两块高度) → 同一视觉行；行内再按 x 左→右。**聚类只决定排序键，不合并文本**，输出仍是「每块一行」 |
| 为何不用 layout 的 40% | layout 用「重叠 ≥ 40% × 传入块高」，在密行页上会链式过度合并（实测 p68 把记音/IPA/直译三行串成 89px 一行）；改对称 60% 后 p68 降到 15px |
| 版本 | 古谢经 `v1.1-ocr` → `v1.2-ocr`；文化大观 `v1.0-ocr` → `v1.1-ocr`；古歌走 layout 不受影响 |

## v1.3-ocr：判栏由一维投影改为覆盖度法

**这是本轮的主要发现**：v1.1 记录的「未改动 164 页（单栏 100 + 表格/目录 64）」拆分是错的，
其中 **101 页其实是双栏正文**，行序一直是左右栏按视觉行交错。

| 项 | 内容 |
|---|---|
| 旧法 | 按块左边界排序 + 维护「已见最大右边界」，收集宽度达标的垂直空白带。隐含假设「没有任何块跨越栏线」 |
| 失效实例 | ① p53：底部全宽脚注（宽 1156px = 75% 页宽）横跨栏线，把栏线整条抹掉；② p71：右页边一个孤立「．」制造出第二条候选带，「有且只有一条」不成立；③ p122：栏线中段一个 4px 噪声块把栏线切成两条 |
| 根本缺陷 | 一维投影只看「有没有块跨过」，不看「跨过了多少」；正确判据是「这条带在页面中部、且整页高度上基本无字」 |
| 新法 | 4px 网格累计每个 x 栏上**全部块**覆盖的高度之和，占比 <3% 页高视为空白 → 桥接间隙 ≤max(8px, 0.5% 页宽) 的相邻空带 → 只在页宽 20%-80% 区间内找空带，要求**恰好 1 条** → 再走原有四条（带宽、中心 32%-60%、每栏 ≥6 块、每栏至少 1 个 ≥20% 页宽的块） |
| 为什么覆盖度必须含全部块 | 中途试过「忽略全宽块」，结果把文化大观 p108（单栏正文夹一段双栏引诗）、p270（节日一览表）误判为双栏。脚注只贡献约 2% 页高、通栏正文贡献几十%，这一条正是区分二者的唯一依据 |
| 生效范围 | 古谢经双栏页 **266 → 367**（+101），回退 **0** 页，行序变化 331 页；文化大观 **0 变化**（仍为 v1.1-ocr）；古歌走 layout 不受影响 |
| 版本 | 古谢经 `v1.2-ocr` → `v1.3-ocr`（指向古谢经的旧指针须先按 v1.2-ocr 解析） |
| 工具 | 新增 `render_check.py`（按页出渲染图）、`qc_visual_rows.py`（重刷视觉行待核清单） |

## 二、关键教训：兜底判据必须按册开关

兜底判据是**弱判据**——它只问「页面正中是不是基本无字」，不问「那是不是一条栏线」。
逐页看图后发现它在双栏册里准、在单栏册里错：

| 册 | 兜底新增页 | 逐页看图结论 |
|---|---|---|
| 古谢经（主判据判出 367/430 = 85% 双栏） | 30 页 | **全部是真双栏诗歌页**（p17 穆考（头经）、p224 构咪（梯坎歌）、p291 穆撰（祭灵经）、p363、p412、p420 十五 改凶煞走转场歌…），栏线被居中标题或通栏脚注（p17 注①②）盖住 |
| 文化大观（主判据判出 0/524 双栏） | 3 页 | **全部是假阳性**：p86 图文混排（文字绕图，绕出的窄栏不是独立正文列）、p513 文保单位名录表（核心区 3 条列缝）、p520 两栏名录（名称↔所在地逐行配对） |

两类页的几何特征**高度相似**（都在页面正中留下 2%~10% 的残余覆盖），试过的页面级判据
（左右块数均衡、栏填充密度、块贴栏比例、核心空带条数）**没有一个能把它们分开**——
差别是语义的（诗歌双栏 vs 表格/绕图）。故引入**册级先验**：

> 兜底判据只在「本册主体为双栏正文」时成立。由 `books.py` 的 `col_fallback` 开关控制，
> 依据是主判据在该册判出的双栏页占比（古谢经 85% → 开；文化大观 0% → 关）。

实现：`plain_mode.detect_columns/gutter_split/order_plain/restore_plain` 增加
`allow_fallback` 参数，四个调用点（`run_full.py`、`rebuild_plain.py`、`qc_visual_rows.py`、
`inspect_rows.py`）全部按册透传。文化大观因此判栏结果 **0 变化**，仍为 `v1.1-ocr`。
