| 册 | doc_id | 原件页数 | 已识别页 | 行数 | 字符数 | 版式 | canon_version |

> **古歌仅识别了前 300 页**（2026-09-24 用户指定），其余页未处理。其余两册为全本。

**两种版式处理的区别**：

- **layout（古歌）**：四行对照体，做完整版式还原——中文层过滤、垂直重叠聚类成视觉行、栏间补全角空格。
  额外产出 verse 三层对照（音译/直译/意译），意译层经抽验零错误，可直接作知识抽取主文本。
- **plain（古谢经 / 文化大观）**：每识别块自成一行，只做「阅读顺序」修正，不做版式还原。
  古谢经为双栏诗歌（397/430 页检出双栏，先左栏后右栏）；文化大观为单栏散文。

## 三、数据格式

### `*_full_zh.txt` — 纯文本，E0 索引器可直接消费

每页以页标记开头，其后逐行正文：

```
[p0001]
（第一行）
（第二行）
...
[p0002]
...
```

### `*_full_lines.jsonl` — 行级结构化数据

每行一条 JSON 记录，两种 `type`：

- `type: "page"`：页级元信息——`doc_id`、`page`、`render_w/h`、块数、行数、
  `col_split`（双栏页记栏线位置 `{"n_cols":2,"gutter_px":[gl,gr]}`）、`canon_version`、`engine`
- `type: "line"`：行级记录——`text`、`line_no`、`bbox_px`（x/y/w/h，3× 像素空间）、`conf`（置信度）、`blocks`

### `lines/pNNNN.jsonl` — 逐页记录

与 `full_lines.jsonl` 同构，但按页分文件（页级原子写入，中断可续跑）。知识图谱需要「精确到页」的溯源指针时，以本目录为准。

## 四、引用纪律（重要）

**证据指针协议**：`doc_id + page + line_no`。只要语料内容或行序有变动，`canon_version` 就必须升级，
否则旧指针会**静默失效**（指向错误的行）。引用本目录语料时，请一并记录所依据的 `canon_version`。

版本历史（详见 `04_质检记录/质检报告.md`）：

| 版本 | 范围 | 变更 |
|---|---|---|
| `v1.0-ocr` | 三册首版 | 首次全量识别 |
| `v1.1-ocr` | 古谢经 / 文化大观 | 古谢经新增双栏切分（266 页）；文化大观新增视觉行聚类 |
| `v1.2-ocr` | 古谢经 | 视觉行聚类，修正行内词序（Vision 对同行各块 y 有抖动） |
| `v1.3-ocr` | 古谢经 | 判栏由一维投影改为覆盖度法，双栏页 266 → 367 |
| `v1.4-ocr` | 古谢经 | 新增兜底判栏，捞回「栏线被跨栏标题/脚注盖住」的页，双栏页 367 → 397 |

> 所有版本升级**只改行序与 line_no，行文本一字未改**（每页重排前后做文本多重集校验）。
> 因此若只关心文本内容，各版本可互换；若依赖行号定位，必须匹配版本。

**已知残留**（内容无损，仅行序）：古谢经 8 页存在原书竖排堆叠字，上字块与整行垂直重叠 <60% 会单独成行，
使该字在阅读顺序里提前一位。未修（放宽阈值会重新引入密行过度合并）。涉及页：p53、p57、p58、p89、p91、p146、p147、p252。

## 六、如何再生成 / 更新

转化流水线代码在 `03_转化流水线/`，与源项目同源：

- `E1_语料层/ocr_engine.py` — Vision OCR 引擎（PDFKit 渲染 + 文本块识别）
- `E1_语料层/layout.py` — layout 版式还原（古歌）
- `全量PDF识别/plain_mode.py` — plain 判栏与视觉行聚类（古谢经 / 文化大观）
- `全量PDF识别/books.py` — 三册配置（PDF 路径、模式、`canon_version`、`col_fallback` 开关）
- `全量PDF识别/run_full.py` — 全量识别入口（断点续跑）
- `全量PDF识别/rebuild_plain.py` — 离线重排（不重跑 OCR，秒级完成，天然幂等）
- `全量PDF识别/verse_mode.py` — 古歌 verse 三层构建
- 质检工具：`render_check.py`、`crop_check.py`、`contact_sheet.py`、`inspect_rows.py`、`qc_visual_rows.py`

> 代码中的 PDF 路径按源项目结构解析（`PROJECT_ROOT/布依族资源/...`）。在本目录复现时，
> 需把 `books.py` 的 `PROJECT_ROOT` 指向 `01_原件PDF/` 的上级，或将三册 PDF 放回 `布依族资源/` 同级结构。
